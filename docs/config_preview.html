Scope & global settings

Phase 1 — Discovery (NMAP)

nmap

Full TCP port sweep with service/version detection.

Why: Enumerate every listening TCP service and its product/version — this inventory is the basis every other test is gated on.

Command: 
nmap -Pn -sS -p- -sV -T4 --open -oA <ws>/nmap/tcp -iL <ws>/targets.txt

Phase 2 — Web service modules

nuclei

Templated detection of CVEs, misconfigurations and exposures.

Why: Community templates catch known CVEs, default creds, exposed panels and misconfigurations across web services.

Command: 
nuclei -l <ws>/web_urls.txt -jsonl-export <ws>/nuclei.jsonl -o <ws>/nuclei.txt -stats -severity low,medium,high,critical -rate-limit 150
sslyze — not found

Parse-friendly JSON TLS scan to corroborate sslscan/NSE.

Why: Second, machine-readable TLS opinion to reduce false positives.

Command: 
sslyze --json_out=<ws>/sslyze/<host>_<port>.json <host>:<port>

Intrusive (off by default)

hydra

Online password guessing against discovered services.

Why: Validates weak/default credentials. INTRUSIVE: lockout/availability risk.

Intrusive — requires explicit per-module authorization below.

Command: 
hydra -L <users> -P <passwords> -o <ws>/bruteforce/<host>_ssh.json -b json ssh://<host>:<port>
Every active test runs only against services nmap finds open.
